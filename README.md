# SmartBand X – Frosted Glass Product Page

A responsive, modern frosted glass product landing page for **SmartBand X**, featuring a dark/light glass theme switcher, interactive pricing & offer calculator modal, clickable feature highlights, and smooth scroll animations.

## Project Structure

```text
smartband-x/

├── style.css    # Frosted glass styling, ambient gradient mesh, responsive grid, and theme variables
├── script.js    # Theme toggle, pricing discount modal, feature pinning, and scroll reveal
└── README.md    # Project documentation
